# صفحه معرفی دوره Microsoft Power BI

این مخزن شامل وب‌سایت فارسی معرفی دوره Microsoft Power BI است. صفحه به‌صورت واکنش‌گرا (Responsive) و راست‌به‌چپ (RTL) پیاده‌سازی شده است.

## امکانات

- معرفی دوره، مدرس، سرفصل‌ها، برنامه و هزینه‌ها
- نمایش لوگوهای انجمن‌ها و دانشگاه‌های همکار
- لینک‌های ارتباطی و ثبت‌نام
- طراحی مناسب تلفن همراه و رایانه

## ساختار مخزن

```text
.
├── index.html   # تمام کد HTML، CSS، JavaScript و تصاویر جاسازی‌شده
├── .nojekyll    # انتشار مستقیم صفحه در GitHub Pages
├── .gitignore
└── README.md
```

> تصاویر این نسخه داخل `index.html` جاسازی شده‌اند و پوشهٔ تصویر جداگانه لازم نیست. برای بارگذاری فونت «وزیرمتن» از Google Fonts استفاده می‌شود؛ در صورت عدم دسترسی به اینترنت، فونت جایگزین سیستم نمایش داده می‌شود.

## انتشار سایت با GitHub Pages

1. در [GitHub](https://github.com/new) یک مخزن تازه، مثلاً با نام `powerbi-course`، بسازید. حالت **Public** برای انتشار عمومی ساده‌تر است.
2. فایل‌های همین پوشه (به‌ویژه `index.html` در ریشه) را با گزینه **Add file → Upload files** در مخزن بارگذاری کنید و **Commit changes** را بزنید. دقت کنید فایل‌های مخفی نظیر `.nojekyll` هم در مخزن قرار بگیرند.
3. در مخزن وارد **Settings → Pages** شوید.
4. در قسمت **Build and deployment**، منبع **Deploy from a branch**، شاخه **main** و مسیر **/(root)** را انتخاب و **Save** کنید.
5. پس از تکمیل انتشار، سایت معمولاً در نشانی زیر در دسترس قرار می‌گیرد:

   `https://YOUR-USERNAME.github.io/powerbi-course/`

   به‌جای `YOUR-USERNAME` نام کاربری GitHub و به‌جای `powerbi-course` نام مخزن را وارد کنید.

## ویرایش صفحه

برای تغییر متن، قیمت، لوگو یا لینک‌های ارتباطی، فایل `index.html` را ویرایش و تغییرات را در مخزن ثبت کنید. بعد از انتشار مجدد GitHub Pages، نسخه جدید در سایت دیده می‌شود.

## اجرای محلی

فایل `index.html` را با مرورگر باز کنید؛ برای عملکرد پایه به نصب پکیج یا سرور نیاز نیست.

## نکته

پیش از عمومی کردن مخزن، نام‌ها، اطلاعات ثبت‌نام، لینک‌ها و مجوز استفاده از لوگوهای دانشگاهی/سازمانی را بررسی کنید.
